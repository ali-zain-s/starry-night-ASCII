# Starry Night

Van Gogh's *The Starry Night*, animated live in your terminal. A small
vortex flow-field simulation pushes hundreds of particles into swirling
brush-stroke trails, pulsing stars and a glowing crescent moon hang over a
silhouetted cypress tree and village skyline. Pure Python standard library,
ANSI truecolor, no dependencies.

## Run

```bash
python3 starry_night.py
```

Ctrl+C to quit.

## Options

```bash
python3 starry_night.py --fps 24 --particles 400
python3 starry_night.py --duration 10   # auto-quit after 10s
```

Works best in a truecolor terminal (iTerm2, VS Code, most modern terminal
emulators) with a wide/tall window — the bigger the window, the bigger the
sky.
